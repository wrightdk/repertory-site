# Repertory site

Landing page for [Repertory](https://github.com/wrightdk/Repertory), a free Android app for working through filmographies.

Live at https://wrightdk.github.io/repertory-site/

A single static page (`index.html` plus `assets/`), served by GitHub Pages from `main`. The privacy policy is `PRIVACY.md`; the page loads it and shows it at `#privacy`, so edit that file to change the policy.
